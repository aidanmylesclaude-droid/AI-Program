# 2.2 How Claude Code reads the vault: direct file access vs Obsidian MCP/plugins
**Stage / Module:** 2 · **Status:** done · **Date taught:** 2026-11-20
**Builds on:** 1.1.6 (Claude's tools), 1.5.3 (MCP, least privilege), 1.6.4 (third-party code and attack surface), 2.1 (vault = plain files).

## What you'll learn
Claude Code already reads your vault without any add-on. When an Obsidian plugin or MCP server would help, and why you don't need one now.

## Key terms
- **Direct file access:** Claude Code's built-in tools (Read, Grep, Glob, Edit) open the `.md` files on disk, just like Notepad would.
- **Obsidian plugin:** an add-on that runs *inside* Obsidian. **Core plugins** are built by Obsidian; **community plugins** are written by other people (third-party code, off in restricted mode).
- **Obsidian MCP server:** a community-made bridge that lets an AI app talk to Obsidian, usually through a community plugin that opens a local web API (a "REST API") protected by a key.
- **Attack surface:** everything an attacker could try to misuse. Every plugin, server and key adds to it.

## The problem this solves
Videos often say "connect Claude to Obsidian with MCP!" That's real, but it solves a problem you don't have: **Claude Code in this folder can already see every note.**

## Explanation
| | Direct file access (what you have) | Obsidian plugin + MCP server |
|---|---|---|
| Setup | None | Community plugin + MCP server + API key |
| Needs Obsidian running? | No | Usually yes |
| Read, search, edit notes | Yes | Yes |
| Extra Obsidian features (its search index, open a note in the app) | No | Some |
| Works from Claude chat / desktop chat (no file access) | No | **Yes: this is its real use** |
| Third-party code, key to protect, attack surface | None | More of all three |
| Label | **Established** (built into Claude Code) | **Experimental** (community-made, changes fast) |

**Verdict for you:** direct file access. Revisit an MCP server only if you need your vault from a *chat* app that can't see files.

## Two gotchas when both of you edit the vault
1. **Renaming:** rename or move a note **in Obsidian**; it updates every `[[link]]` to it. If Claude renames a file with its file tools, links are **not** updated automatically (ask Claude to fix them too).
2. **Same note at once:** don't type in a note while Claude is editing it. Obsidian reloads changes from disk, but simultaneous edits can overwrite each other.

## Example from your projects
Your trading agent's research notes live in the vault. Claude Code reads them directly while working in the folder. Only if you later wanted to ask about them from your phone's Claude chat would an MCP bridge be worth evaluating (Optimization Center review first).
