# 2.3 Organizing notes: note types, links, tags, properties, templates
**Stage / Module:** 2 · **Status:** done · **Date taught:** 2026-11-20
**Builds on:** 1.1.5 (YAML), 1.5.6 (memory: if it must survive, write it down in the right place), 2.1–2.2.

## What you'll learn
Which kind of note goes where, when to use a link vs a tag vs a folder, what properties are, and how templates keep notes consistent. Then: your first permanent concept note.

## Key terms
- **Note type:** what a note is *for*, which decides where it lives and how long it stays (table below).
- **Permanent note:** one idea, in your own words, linked to related ideas. The heart of a second brain.
- **Tag:** a label like `#security` that groups notes across folders.
- **Properties (frontmatter):** a small block of YAML (1.1.5) between two `---` lines at the very top of a note: fields like `type`, `status`, `created`. Obsidian shows it as a neat table; Claude reads it as text.
- **Template:** a pre-made note skeleton you copy, so every note of a type has the same parts.
- **Unresolved link:** a `[[link]]` to a note that doesn't exist yet. Obsidian shows it faded; clicking it creates the note. A to-do list for your brain.

## The problem this solves
A pile of notes becomes as useless as no notes: you can't find things, and neither can Claude. A few simple rules keep it findable for both of you.

## Explanation
**Note types (now in `99-System/CONVENTIONS.md`):**
| Type | What | Where |
|---|---|---|
| Temporary | Raw ideas, links, tangents | `00-Inbox/`: sort weekly |
| Active | What we're working on now | `01-University/` |
| Permanent | One idea, own words, linked | `02-Knowledge/concepts/` |
| Reference | Decisions, project briefs, tool reviews, stack | `02-Knowledge/decisions/`, `projects/`, `03-Optimization-Center/` |
| Long-term record | What happened | `02-Knowledge/sessions/`, archive |

**Folder, link or tag?** Folder = where it *lives* (one place only). Link = a *specific* connection ("this idea depends on that one"). Tag = a *broad theme* across folders. Prefer links; keep tags few, or they turn into clutter.

**Properties** make notes sortable and filterable (by status, type, date) in Obsidian, and give Claude reliable fields to read.

**Templates:** ours live in `99-System/templates/` (lesson, concept, tool review). Obsidian's **Templates core plugin** (made by Obsidian, not third-party) can insert one with a command. Optional: Settings → Core plugins → Templates → set the folder to `99-System/templates`.
