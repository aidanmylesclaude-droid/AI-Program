## Part 1: Memory systems, from shortest-lived to longest
| Memory | Who writes it | Lasts | Loaded | You've used it? |
|---|---|---|---|---|
| **Context window** | The conversation itself | One session | Always (it *is* the session) | Yes: everything we say |
| **CLAUDE.md** | You (and Claude, with your OK) | Permanent | Every session, in full | Yes: global + AI-Program |
| **Auto memory** | Claude, on its own | Permanent, per project | First 200 lines or 25 KB, every session | Folder exists for AI-Program but is **empty**: this program stores memory in files we designed |
| **Skills** | You | Permanent | Only when used | Not yet (Stage 3.2) |
| **Files / vault** (`PROGRESS.md`, lessons, Obsidian) | You and Claude | Permanent, and backed up in Git | When read | Yes: the backbone of this program |
| **Database** (e.g. SQLite) | Your agent's code | Permanent, structured | When queried | Not yet: for agents that track many records (trades studied, video stats) |

**The design rule (1.2.4): if it must survive, write it down, in the right place.** Rules go in CLAUDE.md; procedures go in skills; progress and knowledge go in files; lots of structured records go in a database.

## Part 2: The "you don't need this (yet)" list
| Thing you'll see in videos | Verdict for you now | Why |
|---|---|---|
| Vector databases / "RAG" for your notes | **Not yet** | At your size, plain Markdown + search works. Revisit only if the vault gets huge (Stage 2). |
| Agent frameworks (LangChain, CrewAI, AutoGen…) | **Not yet** | Claude Code and Anthropic's own SDKs cover Stage 4. Adding a framework adds a layer to learn and debug. |
| "Agent swarms" of 10+ agents | **Mostly hype** for you | One good agent first (1.5.5: measure before multiplying). |
| Dozens of MCP servers | **No** | Least privilege (1.5.3). |
| Fine-tuning your own model | **No** | Expensive and unnecessary; good instructions + files do the job. |
| Running local models (Ollama etc.) | **Not for your goals now** | Weaker models, more setup; your agents need strong reasoning. |
| Bypass-permissions mode | **Never on your PC** | 1.2.5. |
| Paid "AI trading bot" or "passive income agent" courses | **Hype, and risky** | No system guarantees profits; this program's trading work is research and education only. |
| n8n / Zapier-style automation | **Maybe later** | Useful for simple fixed workflows; covered in 1.6.1. |
| Docker / containers | **Later** | For isolating agents that run unattended (Stage 5). |
When something new appears, the Optimization Center's review template decides: implement now, save for later, or ignore.
