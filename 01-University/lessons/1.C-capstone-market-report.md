# 1.C Stage 1 capstone: market-data report
**Stage / Module:** 1 / capstone · **Status:** done · **Date taught:** 2026-11-20
**Builds on:** everything in Stage 1. Code: `01-University/exercises/capstone-1.C/`.

## What you'll learn
That you can already read, check, run and safely save the output of a real data workflow, and recognise every piece of it.

## Key terms
- **Capstone:** a final project that combines a stage's lessons into one working thing.
- **Time series:** the same measurement over a run of dates (here: one rate per currency per date).
- **CSV:** "comma-separated values", a plain-text table that spreadsheets open. One row per line.
- **Deduplication:** not adding the same record twice.
- **Strengthened / weakened:** if 1 dollar buys *more* euros than before, the dollar strengthened against the euro.

Proves the Stage 1 foundation works end to end before Stage 2 (Obsidian) and long before agents (Stage 4).

## Knowledge check (2 questions)

## Answers
- Prediction: no. It sees today's row already exists and skips it (the log says so). The report and raw data files are rewritten with the same day's data.
1. No. One week says nothing reliable about the next; no system predicts or guarantees moves. (Also: reference rates, not tradable prices.)
2. "What it WRITES" and "What it SENDS" (the four questions): they show what it can change or send out. Then confirm with a scan or by reading the code, since a comment can be wrong.
