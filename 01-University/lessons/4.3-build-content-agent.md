## What you'll learn
How a real agent call looks in code: load the key, give the model a job and one tool, let it loop, check the result, save it, log the cost.

## Key terms
- **`anthropic` package:** Anthropic's official Python SDK for the Claude API.
- **System prompt:** the standing instructions for the model (here: your design's rules).
- **Server tool:** a tool Anthropic runs for the model (web search). Our code doesn't execute it; the API does, and returns results with **citations** (source links).
- **`pause_turn`:** the API pausing a long search turn; our code sends it back to continue (with a limit).
- **Usage:** the token and search counts the API returns with every answer, so cost can be calculated and logged.
- **401:** the API's "your key wasn't accepted" error.

## Design change from 4.2 (smaller privilege)
DESIGN.md listed a `save_draft` tool. Better: **our code** saves the model's final answer to the drafts folder. The model never chooses a file path, so it has *no* write tool at all: only web search.

## Cost estimate (to check against the real usage log)
One run: up to 10 searches (≤ 10 cents) + tokens. Search results count as input tokens, so a run is roughly **$0.10–0.50** on Claude Opus 5.5. Your $5 credit covers at least 10 runs; your spending limit caps the rest.

## Steps
1. Venv + `anthropic` + `python-dotenv` (your approval).
2. `test_key.py`: one tiny call. Prints a reply, or explains a 401.
3. `agent.py`: the v1 agent. Runs the search loop (max 10 searches, max 5 continuations), checks the output against the design's done check, saves the draft, logs tokens and cost.
4. First real run; you and Claude read the draft and check one fact's sources.
