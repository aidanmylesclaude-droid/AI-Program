## What you'll learn
The five ways your first agent could be built, who runs what in each, what each costs, and which one fits v1 of the trading research agent.

## Key terms
- **Harness:** the loop around the model that sends messages, runs requested tools and feeds results back (1.6.2). Claude Code is a harness.
- **Hosting / deployment:** the computer the agent actually runs on (your PC, or a cloud server).
- **Claude API (Messages API):** Anthropic's pay-per-token service your code calls directly. Needs an **API key** from a Claude Console account, which is **separate from your Pro plan** and billed separately.
- **SDK (software development kit):** a library that makes calling a service easy from a language like Python.
- **Tool Runner:** a helper in Anthropic's normal Python SDK that runs the tool loop for tools *you* define.
- **Beta:** available and supported, but still changing.

## The five options
| # | Option | You write | Who runs the loop / where it runs | Pays with | Label |
|---|---|---|---|---|---|
| 1 | **Claude API + your own tools** (manual loop or Tool Runner, Python `anthropic` SDK) | The tools (and optionally the loop) | You / your PC | API key, per token | Established |
| 2 | **Claude Agent SDK** (`claude-agent-sdk`, Python/TS): "Claude Code as a library" | A prompt + options | The SDK (Claude Code's harness, built-in file/shell/web tools) / your PC | API key, per token (docs: third-party apps may not use claude.ai login) | Established |
| 3 | **Managed Agents** | An agent config + your tool results | **Anthropic** runs the loop **and** a cloud sandbox; can run on a schedule | API key: tokens **plus session runtime**; keeps session history until deleted | **Beta** |
| 4 | **Claude Code headless** (`claude -p "..."`) | A prompt (+ skills, CLAUDE.md) | Claude Code / your PC | Your Pro plan's usage limits | Established (you've used it) |
| 5 | **No-code tools** (n8n, Zapier, Make) | Drag-and-drop steps | The tool's service | Their subscription + API | Established, but builds **workflows**, not agents (1.6.1) |

## Which fits trading agent v1?
Anthropic's own advice is "start simple" and its four checks (1.6.1). For **your v1**, a research agent that's education-only:
- **Recommended: option 1, Claude API + tool use in Python.** It runs on your PC, every step is visible and testable (pytest, 3.4), it reuses everything you know (venv, `.env`, logs, checks, tool gate from 1.6.4), and it teaches the loop instead of hiding it. Cost for a daily report is pennies to a few dollars a month (1.5.5 table).
- **Why not Managed Agents first?** It's the default Anthropic suggests for hosted agents and great for scheduled runs (Stage 5), but it's beta, adds runtime billing, stores session history on Anthropic's side, and hides the loop you're learning. Re-review at Stage 5.
- **Agent SDK:** strong when the agent must read/write files and run commands; more power (and risk) than a research agent needs. Later, via `/tool-review`.
- **Headless `claude -p`:** fine for personal automations on your plan (you used it for proof tests), but not how you'd build a product, and plan limits aren't designed for heavy unattended use.
- **No-code:** not an agent; skip.
