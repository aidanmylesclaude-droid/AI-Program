## What you'll learn
How to audit what your setup already loads, and how to add exactly one useful thing: your first skill.

## Key terms
- **Audit:** checking what's actually there before adding anything.
- **Always-loaded vs on-demand:** CLAUDE.md is read in full every session (costs context every time); a skill's body loads only when used (1.5.4).
- **`disable-model-invocation: true`:** a skill setting so Claude never starts it on its own; only you can, by typing `/name`.
- **Synced skills:** skills you enabled on claude.ai that Claude Code downloads automatically (your `pdf`, `docx`, `deep-research` etc.). Made by Anthropic, not by you.

## The problem this solves
Videos push "the 20 skills / hooks / MCPs every power user needs". Each one costs context, attention or attack surface. The right number is: what you actually repeat.
