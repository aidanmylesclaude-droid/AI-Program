# 1.6.1 Chatbot → assistant → automated workflow → agent → multi-agent system
**Stage / Module:** 1 / 1.6 · **Status:** done · **Date taught:** 2026-11-20 · *(includes old 1.5.10: automation tools vs agents)*
**Builds on:** 1.2.2 (chat vs Claude Code), 1.2.3 (agent loop), 1.5.1–1.5.5 (APIs, MCP, subagents, cost).
**Source:** Anthropic, "Building effective agents" (anthropic.com/engineering), checked 2026-11-20.

## The ladder
| Level | What it is | Who decides the steps? | Example in your projects |
|---|---|---|---|
| **1. Chatbot** | Answers messages. No tools | You, every message | Asking the Claude app to explain RSI |
| **2. Assistant** | A chatbot with some tools (search, connectors), one request at a time | You start each task; it may use a tool | Claude chat looking up a platform rule |
| **3. Automated workflow** | **Fixed steps in a fixed order**, triggered by a time or event. Steps may include an AI call | **The designer, in advance** | Every day at 6pm: fetch rates → ask Claude for a summary → save to a file (`fx_rates.py` + a scheduler) |
| **4. Agent** | Given a **goal**, it plans, picks tools, observes, and loops until done (1.2.3) | **The model, while running** | "Research whether this setup is worth studying, and explain the risks." It decides what data to pull and when it's done |
| **5. Multi-agent system** | Several agents (or an orchestrator plus workers) splitting a goal | A lead agent coordinates | Your future mega agent: orchestrator plus research, script and analytics workers |

Anthropic's definitions: **workflows** are "systems where LLMs and tools are orchestrated through **predefined code paths**"; **agents** are "systems where LLMs **dynamically direct their own processes** and tool usage."

## Automation tools (n8n, Zapier, Make)
Visual tools that connect apps with **triggers and fixed steps** ("when X happens, do Y, then Z"), and can include an AI step. They build **level 3 workflows**, not agents.
- **Good for:** simple, repeatable plumbing, like "new video published → log it in a spreadsheet".
- **Labels:** Zapier and Make **established** (paid plans); n8n **established** (open source, self-hostable).
- Not needed yet. A Python script plus a scheduler does the same for your first projects (Stage 5).

## Start at the lowest level that works
Anthropic: "finding the simplest solution possible, and only increasing complexity when needed." Before building an agent, check four things (from Anthropic's guidance):
1. **Complexity:** is it multi-step and hard to spell out in advance?
2. **Value:** is the result worth the extra cost and time?
3. **Viability:** is the model good at this kind of task?
4. **Cost of error:** can mistakes be caught and undone?
If any answer is "no", use a workflow or a single AI call instead. **Workflows are cheaper, faster and more predictable; agents are more flexible.**

## Knowledge check (2 questions)
1. "Every morning at 8, fetch yesterday's TikTok stats and save them to a file." Workflow or agent? Why?
2. Which of the four checks fails for "an agent that places trades automatically"?

## Answers
1. Workflow: the steps are fixed and known in advance; nothing needs deciding at run time.
2. Cost of error: real money, hard to undo (and it's outside this program's research-only rule).
