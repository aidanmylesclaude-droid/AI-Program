## What it is
An **API key** is a secret string that identifies *you* to a service, a bit like a password for a program. Whoever has it can use your account: your quota, your data, sometimes your money.

## Why it exists
Free, open APIs like Frankfurter (1.5.1) don't need one. Most useful ones do (real market data, YouTube, Etsy, Claude's own API) so they can track usage, enforce limits and bill you. A missing or wrong key typically gets **401** or **403** (1.5.1).

## Key terms
- **Secret:** anything that grants access: API keys, passwords, tokens.
- **Environment variable:** a named value a program can read from its surroundings, e.g. `MARKET_API_KEY`. In Python: `os.environ.get("MARKET_API_KEY")`.
- **`.env` file:** plain `NAME=value` lines (1.1.5) that a program loads into its environment variables at start-up.
- **python-dotenv:** an established package that loads `.env` for you. **Install name `python-dotenv`, import name `dotenv`.** They're different, which is common, and exactly why you check names on pypi.org (1.4.2).
- **Masking:** showing only part of a secret (e.g. the last 4 characters) to confirm which one is in use.
- **Revoke / rotate:** cancel a key at the provider and issue a new one.

## How it works
```
.env (on your PC only, ignored by Git)      script                       API
MARKET_API_KEY=xxxxxxxx   ── load_dotenv() ──►  key = os.environ.get(...)  ── sends key ──► service
```
**The key lives in exactly one place, `.env`:** never in the code, never in Git, never in a chat, never in a screenshot.

**Five rules**
1. **`.gitignore` first** (1.3.4). AI-Program's root `.gitignore` already covers `.env` in every subfolder.
2. **Type real keys into `.env` with Notepad**, not on the command line. Typed commands can be saved in PowerShell's history file.
3. **Never print a key.** Output ends up in terminals, logs, screenshots and chats. Print a mask at most.
4. **Never paste a real key to Claude or any AI.** Claude only needs to know the key *exists*, not its value.
5. **If a key leaks** (chat, commit, screenshot): **revoke it at the provider first**, then make a new one. Deleting the message or file isn't enough (1.3.3).

**Honesty about this setup:** in Auto mode Claude Code *can* read files in the project, including `.env`. The program rule is that Claude doesn't, but a rule in `CLAUDE.md` is advice, not enforcement (1.1.7). The enforced version is a settings `deny` rule like `Read(./.env)`. We'll set that up in Stage 3 (security hardening).

## How it connects to Claude Code
Claude writes scripts that *read* `os.environ`, and you put the value in `.env`. MCP servers (1.5.3) usually take keys the same way, through environment variables in their configuration.

## When you'd need it / does it matter for your projects?
Yes: market-data providers (trading), YouTube and TikTok APIs (content), Etsy and eBay APIs (e-commerce), and the Claude API itself (Stage 4). **Established practice.**
