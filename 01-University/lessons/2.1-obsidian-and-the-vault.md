## What you'll learn
What Obsidian does (and doesn't do), why a folder of linked notes works as memory for you *and* Claude, and how to open `AI-Program` as your vault.

## Key terms
- **Second brain:** a trusted place outside your head where notes, decisions and ideas are kept and linked, so you can find and build on them later.
- **Obsidian:** a free app that shows a folder of Markdown (`.md`) files as a linked, searchable notebook.
- **Vault:** the folder Obsidian opens. Ours is `C:\Users\aidan\AI-Program`. The notes stay ordinary files in it.
- **Wikilink:** a link written `[[note name]]`. Click it to jump to that note. `HOME.md` already uses them.
- **Backlinks:** the list of notes that link *to* the note you're reading.
- **Graph view:** a map of notes as dots, with lines for links.
- **Restricted mode:** Obsidian's setting that keeps community plugins (add-ons written by other people) switched off. It's on by default.

## The problem this solves
Your program already lives in Markdown files, but reading them in a terminal or Notepad is clumsy, and you can't see how they connect. Obsidian makes the same files easy to read, link, search and browse, **without moving or converting them**.

## Explanation
- **Plain files, no lock-in:** Obsidian stores notes "locally as plain text Markdown files" (obsidian.md). Claude Code reads the very same files (Lesson 2.2). Git backs them up (Stage 1.3).
- **Two readers, one folder:** you read and edit in Obsidian; Claude reads and edits with its file tools. Neither needs the other running.
- **What it is NOT:** not an AI, not a cloud service, not a database. It doesn't send your notes anywhere unless you add Sync or Publish.
- **Hidden folders are skipped:** Obsidian ignores folders whose names start with a dot, so `.git` and `.venv` don't clutter the vault.
- **It adds one folder:** `.obsidian/`, holding its settings for this vault. Part of it (`workspace.json`, which remembers open tabs) changes on every click, so we tell Git to ignore that file.

## Cost and label
**Established.** The app is free, including commercial use ("Free without limits"). Optional paid add-ons, checked 2026-11-20: Sync $4–5/month, Publish $8–10/month per site. **You need neither:** Git already backs up and syncs through GitHub.

## Hands-on exercise (your part: install and open)
1. Go to **obsidian.md/download** (the official site only: 1.4.2 typosquatting applies to apps too). Download the Windows installer and run it.
2. In Obsidian's start screen, choose **"Open folder as vault"** (not "Create new vault").
3. Pick `C:\Users\aidan\AI-Program` and click **Select Folder**.
4. If it asks about trusting the vault or community plugins, choose the option that keeps **restricted mode** on (plugins off). We'll decide on plugins in 2.2.
5. In the left sidebar, open **HOME**. Click the **Progress** link.
Claude then checks the `.obsidian` folder and updates `.gitignore`.
